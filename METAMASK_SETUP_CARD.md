## 📋 Setup Steps (5 Minutes)

### **Step 1: Install MetaMask**
- Go to: https://metamask.io/download/
- Click "Install MetaMask for [Your Browser]"
- Add extension

### **Step 2: Create Wallet**
1. Open MetaMask
2. "Get Started" → "Create a new wallet"
3. Set password
4. **SAVE YOUR SEED PHRASE** (write on paper!)
5. Confirm seed phrase
6. Done!

### **Step 3: Add Qubetics Network**
1. Click network dropdown (top left)
2. "Add network" → "Add network manually"
3. Copy these EXACTLY:
   ```
   Network Name: Qubetics Testnet
   New RPC URL: https://rpc-testnet.qubetics.work
   Chain ID: 9029
   Currency Symbol: TICS
   Block Explorer URL: https://testnet.qubetics.work
   ```
4. Click "Save"
5. Switch to "Qubetics Testnet"

### **Step 4: Get Your Wallet Address**
1. Click account name in MetaMask
2. Address shows below (0x1234...5678)
3. Click to copy 📋

### **Step 5: Get Testnet Tokens**
**Option A: Discord**
- Join Qubic Discord
- Find faucet channel
- Request TICS tokens with your address

**Option B: Faucet Website**
- Try: https://faucet.qubetics.work
- Paste your wallet address
- Request tokens

## 🆘 Troubleshooting

### Can't find Chain ID field?
- Make sure you clicked "Add network **manually**"
- Don't use "Add popular networks"

### Network won't save?
- Check all fields are filled
- Chain ID must be exactly: 9029
- RPC URL must start with https://

### No testnet tokens?
- Check you're on Qubetics Testnet (not Ethereum)
- Wait 5-10 minutes
- Try Discord faucet
- Ask in community

### App won't connect to wallet?
- Make sure MetaMask is on Qubetics Testnet
- Restart MetaMask
- Clear app cache
- Rebuild app
